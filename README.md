# Schedulix — CPU Scheduling Simulator

Schedulix is an interactive web-based CPU scheduling simulator designed to help students understand operating system scheduling algorithms through visual process execution and performance metrics.

🌐 **Live Demo:** https://schedulix-mauve.vercel.app/

## Features

- Simulate CPU scheduling using the algorithms supported by the application.
- Enter process details such as arrival time and burst time.
- Visualize process execution using a Gantt chart.
- Calculate and compare scheduling metrics, including waiting time and turnaround time.
- Explore how scheduling decisions affect process execution.

## Tech Stack

- React.js
- JavaScript
- Vite
- HTML and CSS

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project locally.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/hpallavi23/Schedulix.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Schedulix
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Project Purpose

Schedulix was developed as an educational Operating Systems project to make CPU scheduling concepts easier to explore and understand through interactive visualization.
